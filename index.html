How this measurement works

All engines load the same gear atlas and draw a rotating sprite on a 640 × 360 WebGL canvas, resolution 1, with antialiasing. Each reports from its normal render loop after the first frame containing the image. A shared microtask waits until the complete render stack returns, then calls WebGL finish() to wait for GPU completion. The primary time includes this synchronization. This does not measure physical screen presentation.

Every sample uses a fresh browser context with HTTP cache cleared and service workers blocked. Code, images and other resources must be loaded for every measured navigation. Engine order rotates each round. Cold cache does not mean a fresh OS, browser process, DNS cache or GPU driver.

The local runner applies the selected download/upload bandwidth and request latency through Chromium's DevTools protocol. No CPU throttling is applied. Text responses use gzip. Bare retains its standard bootstrap and parallel initial-asset preloads; peers use native atlas loaders. The dashboard browser's cache and DevTools settings do not control the separate runner.

Requires the local server: run npm start. Default browser: installed Edge; set BENCHMARK_BROWSER=chrome for installed Chrome. Static hosting alone cannot run controlled tests. Render time and bundle size remain separate future benchmarks.
