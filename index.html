How this measurement works

Every engine loads the same atlas and draws a rotating sprite on a 640 × 360 WebGL canvas at resolution 1 with antialiasing. Each reports from its own render loop after the first frame with the image; a shared hook then waits for the render stack to return and calls WebGL finish(), so GPU completion is included. Physical screen presentation is not.

Each sample runs in a fresh browser process with an empty HTTP cache and service workers blocked, so code, images and shaders load every time. A blank WebGL page runs first so GPU process start-up is excluded, as in an already-open browser. Engine order rotates each round. OS, DNS and GPU driver caches are not reset.

Network profiles apply bandwidth and latency limits through Chromium DevTools; CPU is not throttled. Responses are gzipped. Bare keeps its standard bootstrap and preloads; the others use their native atlas loaders.
